# 기본 애니메이션 (Idle · Walk · Wave · GetUpBack · GetUpFront) — 리깅한 캐릭터 (model_chibi.txt + model_chibi_rig.txt) 위에서
#   nova model batch docs/examples/anim_basic.txt → nova model export Resources/Packages/Character/Animations/Nova_Basic.glb
# 회전 = 도 (월드 축, 부모 위에): 다리 pitch - = 앞으로, 아래팔 pitch - = 팔꿈치 앞으로 굽힘, 왼팔 roll - / 오른팔 roll + = 몸 밖으로
# 이 치비의 팔은 쉬는 자세에서 25° 벌어져 있다 → 몸에 붙이려면 왼팔 roll +17 · 오른팔 -17 (리타게팅은 쉬는 자세 기준 회전을 옮긴다)
# 엔진은 Humanoid 리타게팅으로 어떤 캐릭터에든 (VRoid · Mixamo · UE 마네킹)
